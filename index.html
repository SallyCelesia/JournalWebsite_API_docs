Journal API Reference

CRUD in Database

POST /auth/register

Creates a brand new user account. This endpoint is public and does not require a token.

Request Body
{
  "name": "user1",
  "email": "user1@example.com",
  "password": "pass121323"
}
User Result (201 Created)
{
  "id": "665f1c2a9b1e8a0012ab34cd",
  "name": "user1",
  "email": "user1@example.com",
  "isAdmin": false,
  "createdAt": "2025-06-01T10:15:30.000Z"
}
Error Responses
400 Bad Request 
{ "error": "name, email and password are required" }
400 Bad Request 
{ "error": "password must be at least 8 characters" }
409 Conflict 
{ "error": "An account with this email already exists" }
POST /auth/login

    "isAdmin": false,
    "createdAt": "2025-06-01T10:15:30.000Z"
  }

{ "error": "email and password are required" }

{ "error": "Invalid email or password" }

OVERVIEW

Concepts Implemented

Express Routing

Each route uses a method and path (e.g., PATCH /users/:id). Route parameters like :id and :userId are read using req.params.

Middleware Chains

Routes execute functions in sequence (such as requireLogin then requireOwner/requireAdmin). Each function either calls next() or terminates with an error response.

Password Hashing with bcrypt

Passwords are securely stored as hashes, never plain text. Uses bcrypt.hash during registration and bcrypt.compare during login.

JWT Login Tokens

Login generates a signed token valid for 1 hour. Protected routes read it from the Authorization: Bearer <token> header and verify it with JWT_SECRET.

Ownership Checks

requireOwner verifies that the user ID in the URL matches the ID stored in the token, preventing access to other users' data.

Admin Role

The isAdmin flag controls access to /admin/users. requireAdmin reads this directly from the database on every request so role revocations take effect immediately.

Schemas and Models

Mongoose schemas enforce structure and validation rules, mapping to the users and journals MongoDB collections.

Validation

Field constraints (such as month from 1 to 12) run on create and update with runValidators: true, alongside parameter checks in route handlers.

Unique Index

A compound index on {user, month, day} ensures that a user can create at most one entry per day.
